Event Horizon generic-ledger source summary

Branch: codex/generic-ledger-instances

- Stable ID 2 stores immutable instance configuration and the discovered
  observed-ledger profile.
- Canonical ICP uses the fixed legacy `query_blocks` adapter for shared
  admission and observation.
- Every non-ICP Observed Ledger requires ICRC-1, ICRC-3, and `1xfer`.
- The fixed Protocol ICP Ledger remains the admission and funding ledger.
- One backend Wasm contains both adapters; immutable `observed_ledger`
  determines the path.
- Production backend application methods are the `get_instance` and
  `get_pricing` queries only.
- `SURPLUS_CANISTER` remains `None`.

Current evidence is recorded in
docs/codex/generic-ledger-instances-validation.md. No mainnet mutation was
performed during this source work.
