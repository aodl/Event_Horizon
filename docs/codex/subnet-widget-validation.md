## Design and boundaries

The local decorative network thumbnail is fixed at the lower-left, normally
232×140 CSS pixels and 192×108 on narrow or short screens. Safe areas adjust
its inset. The launcher stays visible and keyboard reachable while page
controls have focus; its separate Close action clears the overlay.
A native dialog uses 90vw × 88dvh with 90rem × 62rem caps, and nearly the full
viewport on phones and short screens. Parent controls remain available
when enlarged text requires internal scrolling. No widget animation is added.

The small initializer owns collapsed, expanded and dismissed states, a single
iframe, native dialog listeners, focus and scroll restoration, and disposal.
Escape received by the parent minimises. Cross-origin Escape interception is
not guaranteed. Dismissal is terminal until reload and uses no browser storage.
An initial conventional link supports missing JavaScript or native dialog.

A continuously running map inside the thumbnail is intentionally avoided:
initial loading uses only local SVG, and assigns no iframe URL. Explicit
expansion loads the approved external application; minimisation, dismissal,
pagehide and disposal remove the URL. No Event Horizon backend requests,
network discovery, proxying, message protocol or dependency was added.
The dashboard is trusted for display independently of certified parent assets;
subnet composition proves neither controller removal nor source provenance.

## CSP

Only the page policy gains
`frame-src 'self' https://dashboard.internetcomputer.org`. Explicit `'self'`
is necessary: an actual Chromium regression caught that dashboard-only
`frame-src` blocks the existing same-origin SVG object browsing context.
All previous directives and the separate SVG policy remain unchanged,
including `frame-ancestors 'none'`, the self-only scripts/styles and the
`https://icp-api.io` parent connection allowlist.

## Known limits

No mainnet deployment or backend upgrade is authorised or performed. The current
published Event Horizon origin cannot demonstrate an undeployed CSP; repeat the
smoke after a separately reviewed frontend upgrade. Browser emulation cannot
replace physical iOS Safari/VoiceOver and Android device review. Cross-origin
failures cannot all be detected; the parent always retains controls and external
links. Sandbox popups and top navigation remain intentionally unavailable;
visitors can use the parent links for the full dashboard.

Browser evidence, headers, certificate observations and logs are retained under
ignored `observations/subnet-widget/`. Browser launch used existing libraries
from `/home/codexdev/.cache/browser-libs/root/usr/lib/x86_64-linux-gnu` via
`LD_LIBRARY_PATH`; no system installation or privilege escalation was used.
